# GymLog AI proxy

Минимальный сервер, который нужен только для AI-функций.
Трекер тренировок работает полностью без него.

## Зачем он нужен

Ключ AI-провайдера нельзя класть в мобильное приложение: бандл Expo скачивается
на устройство и легко распаковывается. Поэтому ключ живёт здесь, а приложение
обращается к этому серверу.

**Что сервер видит:** текущий вопрос, системный промпт и результаты тех запросов,
которые приложение выполнило у себя в SQLite.
**Чего сервер не видит:** вашу базу тренировок. Инструменты выполняются на телефоне.

## Развёртывание (Windows + PowerShell)

```powershell
cd C:\dev\gymlog\server
npm install

# 1. Войти в Cloudflare (откроется браузер)
npx wrangler login

# 2. Создать хранилище лимитов и вписать выданный id в wrangler.toml
npx wrangler kv namespace create RATE_LIMIT

# 3. Задать секреты (в код они не попадают)
npx wrangler secret put ANTHROPIC_API_KEY
npx wrangler secret put DEVICE_TOKEN     # придумайте длинную случайную строку

# 4. Опубликовать
npx wrangler deploy
```

После деплоя вы получите адрес вида `https://gymlog-ai.ваш-аккаунт.workers.dev`.
Его нужно вписать в приложении: **Настройки → AI-тренер → Адрес вашего AI-сервера**.

Проверка, что сервер жив:

```powershell
curl https://gymlog-ai.ваш-аккаунт.workers.dev/health
```

## Смена модели или провайдера

Модель задаётся переменной `MODEL` в `wrangler.toml` — приложение переустанавливать не нужно.
Для перехода на другого провайдера меняется только `fetch` в `src/index.ts`;
формат ответа должен остаться совместимым (`content`, `stop_reason`, `model`).
