# GymLog — персональный трекер тренировок с AI-тренером

Статус: **Этап 1 — архитектура. Кода ещё нет.**

## Документы

- [`docs/architecture.html`](docs/architecture.html) — полный архитектурный план:
  стек, слои, навигация, схема SQLite, каталог упражнений, медиа, аналитика,
  AI Context / AI Tools, безопасный AI API, риски, порядок разработки.

## Кратко о проекте

Персональный workout tracker для iPhone: шаблоны тренировок, большой каталог
упражнений, запись подходов в зале, история, аналитика прогресса и PR,
плюс AI-тренер, работающий на реальной тренировочной истории.

## Стек (проверено на август 2026)

| Слой | Выбор |
|---|---|
| Платформа | Expo SDK 57 / React Native 0.86 / React 19.2 |
| Язык | TypeScript (strict) |
| Навигация | expo-router 6 |
| Данные | expo-sqlite, чистый SQL + repositories, свои миграции |
| Поиск | SQLite FTS5 |
| Состояние | zustand (активная тренировка, таймер, настройки) |
| Графики | react-native-gifted-charts + react-native-svg |
| Разное | expo-haptics, expo-image, expo-notifications (локальные), expo-crypto, expo-secure-store |
| AI | Cloudflare Worker как прокси + Anthropic API; инструменты выполняются на телефоне |

Разработка ведётся на Windows, запуск на iPhone через Expo Go. Mac и Xcode
не нужны до этапа 20 (standalone-сборка через EAS Build).

## Ключевые принципы

1. Надёжность данных: каждый подход пишется в SQLite немедленно, активная
   сессия восстанавливается после краша.
2. Offline-first: без интернета работает всё, кроме AI и ещё не скачанных
   изображений.
3. Все числа считает код (`src/analytics/`), AI только объясняет — модель
   никогда не вычисляет и не выдумывает результаты.
4. Историческая целостность: снимки полей в завершённых тренировках,
   мягкое удаление, миграции без потери данных.
5. Ключ AI-провайдера никогда не попадает в мобильное приложение.
